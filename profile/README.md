# To Do List Planner - Rows With Dates on the Desk You Use

## Closing Notes for To Do List Planner

Treat To Do List Planner as the list for what you will actually do, not as a diary of every idea. Open ToDoList when you sit down. Keep today short. Move finished rows out. Let old ideas stay off the live page.

If you change chairs, take the same file. If you show someone, show them one row and its date. After that, To Do List Planner usually needs almost no explanation.

---

## Quick Start with To Do List Planner

1. **Open To Do List Planner** - Use the ToDoList file you already keep for this desk.
2. **Add one row** - Name a task you will actually do.
3. **Put a date** - Only when the day is real.
4. **Keep the page short** - Rows that are not soon can stay out of the way.
5. **Mark done** - Move a finished row off the live page.
6. **Leave the file** - Do not start a second list for the same job.
7. **Reopen** - The next morning starts from that same file.

## Advanced Use Cases for To Do List Planner

**Scenario 1: A study week** - Put each assignment in ToDoList with the day it is due.
Keep To Do List Planner limited to that week.
**Scenario 2: A chore list** - Use a separate file from work so the piles do not mix.
Dates only where a day really matters.
**Scenario 3: A shared desk** - Your ToDoList file stays in your account.
Do not edit someone else's rows.
**Scenario 4: Friday** - Mark what finished and delete a row you no longer mean.
Reopen the same file on Monday.
